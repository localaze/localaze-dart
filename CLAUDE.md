# localaze-dart

Two packages and an example:

| Folder | What it is | Its rules |
|---|---|---|
| `localaze/` | The pure-Dart runtime and the generator | `localaze/CLAUDE.md` |
| `localaze_flutter/` | The Flutter binding over the runtime | `localaze/CLAUDE.md`, Flutter integration |
| `examples/flutter_app/` | A Flutter demo of every feature | — |
| `contract/` | The specification all three SDKs implement, a submodule | `contract/CLAUDE.md` |

Read `contract/CLAUDE.md` first: it holds the rules for every Localaze SDK. Then the package's own `CLAUDE.md` for what is specific to Dart.
